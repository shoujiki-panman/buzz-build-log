# PROJECT BUZZ — 実フィギュアのバズを、本当に飛ばす

トイストーリーのバズ・ライトイヤーのアクションフィギュア（約264g）を、
実際に飛行するクアッドコプターに改造する個人プロジェクトのビルドログ。

- はんだ未経験の会社員が、AIと分担しながら作る「バイブコーディングをハードウェアに拡張する実験」
- 進捗はXで公開中: [#PROJECTBUZZ](https://x.com/hashtag/PROJECTBUZZ)
- **非営利のファンプロジェクト**です。キャラクターを使う成果物で収益化は行いません

## ゴール

**2026年10月末、バズが部屋を飛ぶ動画を1本公開する。**

進め方の原則: 計測→原因特定→1変更→検証 の1周を守る。シミュレータで通った＝実機OKとは考えない。
ハードは巻き戻せないため、各フェーズの合格条件（テスト）を満たすまで次に進まない。

## 安全について

- はんだ・バッテリー運用・実飛行は人間が判断する（シミュレータで通った＝実機OKとは考えない）
- 初飛行前に技適・航空法（機体登録等）を整理することを必須ゲートにしている
- 飛行プログラムには「人がスティックを動かしたら即座に手を引く」処理を必ず入れる
