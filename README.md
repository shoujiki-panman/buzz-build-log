# PROJECT BUZZ — 実フィギュアのバズを、本当に飛ばす

トイストーリーのバズ・ライトイヤーのアクションフィギュア（約264g）を、
実際に飛行するクアッドコプターに改造する個人プロジェクトのビルドログ。

- はんだ未経験の会社員が、AIと分担しながら作る「バイブコーディングをハードウェアに拡張する実験」
- 進捗はXで公開中: [#PROJECTBUZZ](https://x.com/hashtag/PROJECTBUZZ)
- **非営利のファンプロジェクト**です。キャラクターを使う成果物で収益化は行いません

## 章立て

| 章 | 内容 | 状態 |
|---|---|---|
| 第一章 | バズを目視（LOS）で飛ばす | **進行中**（部品調達完了・輸送待ち） |
| 第0.5章 | シミュレータでFPV視点を体験 | 送信機の着荷待ち |
| 第二章 | FPV参入（カメラ搭載はその先） | 凍結（第一章の初飛行成功が条件） |
| 第三章 | AI自律飛行（専用実験機を想定） | 構想のみ。`sitl/` `motion/` はこの章の先行資産 |

## 機体スペック（2026-07-11時点の設計）

| 項目 | 値 |
|---|---|
| ドナー | バズ・ライトイヤー Transforming Action Figure（素体264g実測） |
| 構成 | X字クアッド、3インチ3枚ペラ |
| プロペラ位置の対角スパン | 約210mm（ダミープロペラ4本の実測。実質クアッド配置） |
| 想定全備重量 | 約440g |
| FC/ESC | SpeedyBee F405 Mini BLS 35A（20×20スタック） |
| モーター | T-Motor F2004 3000KV ×4 |
| ファームウェア | Betaflight |
| 統合方針 | 純正上蓋は非破壊のまま、カーボントッププレートをM3で貫通固定。純正ブームに推力は載せない |

## リポジトリの中身

- [`cad/`](cad/) — カーボントッププレートのパラメトリック設計（OpenSCAD）＋プレビュー画像

## 安全について

- はんだ・バッテリー運用・実飛行は人間が判断する（シミュレータで通った＝実機OKとは考えない）
- 初飛行前に技適・航空法（機体登録等）を整理することを必須ゲートにしている
- 飛行プログラムには「人がスティックを動かしたら即座に手を引く」処理を必ず入れる
