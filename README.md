# PROJECT BUZZ — 実フィギュアのバズを、本当に飛ばす

トイストーリーのバズ・ライトイヤーのアクションフィギュア（約264g）を、
実際に飛行するクアッドコプターに改造する個人プロジェクトのビルドログ。

- はんだ未経験の会社員が、AIと分担しながら作る「バイブコーディングをハードウェアに拡張する実験」
- 進捗はXで公開中: [#PROJECTBUZZ](https://x.com/hashtag/PROJECTBUZZ)
- **非営利のファンプロジェクト**です。キャラクターを使う成果物で収益化は行いません

## ゴール

**2026年10月末、バズが部屋を飛ぶ動画を1本公開する。**

進め方の原則: 計測→原因特定→1変更→検証 の1周を守る。シミュレータで通った＝実機OKとは考えない。
ハードは巻き戻せないため、各フェーズの合格条件（テスト）を満たすまで次に進まない。

## フェーズ（章立て）

| 章 | 内容 | 合格条件（=テスト） | 状態 |
|---|---|---|---|
| 第一章 | バズを目視で飛ばす（画面越しでなく自分の目で見て操縦） | 屋内で1分間の安定飛行 | **進行中**（調達完了・輸送待ち） |
| 第0.5章 | シミュレータでFPV（機体カメラの映像を見ながらの操縦）を体験 | 1分間の定点ホバ＋部屋一周（録画） | 送信機の着荷待ち |
| 第二章 | 実機にFPVカメラを載せる準備 | — | 凍結（第一章の初飛行成功が条件） |
| 第三章 | AI自律飛行（専用実験機を想定） | 3モーションが実機で各1回成功 | 構想のみ。`sitl/` `motion/` が先行資産 |

### 第一章の物理ゲート（この順に1つずつ潰す）

1. モーター検品（目視・手回し）とシャフト実測 → プロペラ選定
2. はんだ練習: 練習基板で10接点、玉の形が安定する
3. 仮組み: ネジ長確認・トッププレート固定
4. 初通電: スモークストッパー（配線ミスでも壊さないための保護器具）経由で発煙なし・電圧正常
5. **ペラなし**で4モーターの回転方向一致
6. 素体ホバリング30秒
7. バズを載せ、テザー（命綱のひも）で繋いだ状態で安定
8. 屋内1分の自由飛行 → 撮影
- **初飛行前の必須ゲート: 技適・航空法（機体登録等）の整理**

## 安全について

- はんだ・バッテリー運用・実飛行は人間が判断する（シミュレータで通った＝実機OKとは考えない）

- 飛行プログラムには「人がスティックを動かしたら即座に手を引く」処理を必ず入れる
