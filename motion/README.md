# バズの飛び方3つ（デモのやり方）

[buzz_motion.lua](buzz_motion.lua) は、シミュレータの中のドローンに
バズの飛び方3つをさせるプログラム。**2026-07-08にシミュレータで3つとも動作確認済み。**

| 番号 | 名前 | 動き |
|---|---|---|
| 1 | burst_takeoff | 垂直に急上昇（ベッドから飛び立つやつ） |
| 2 | room_loop | 部屋をぐるっと一周して中心に戻る |
| 3 | swoop_land | 前に滑り込みながら降りて、ゆっくり着地 |

まだ「骨格版」: 部屋一周は四角く直線で回っているだけ。バンクターン（傾けて曲がる）や
スピード感は、部屋の実測が済んでから本実装する。

## デモのやり方（画面に地図を出して見せる）

ターミナルで:

```bash
cd ~/ardupilot/ArduCopter
sim_vehicle.py --console --map --add-param-file=<このリポジトリ>/sitl/buzz_sitl.parm
```

地図とコンソールの窓が開く。1分ほど待って（GPSをつかむまで）、ターミナルに順番に打つ:

```
mode guided
arm throttle
param set SCR_USER1 1     ← 急上昇
param set SCR_USER1 2     ← 部屋一周（地図をズームすると四角く動くのが見える）
param set SCR_USER1 3     ← 滑り込んで着地
```

コンソールに `BUZZ: ...` というメッセージが出て進行がわかる。
部屋は4m×3mの想定なので、地図はかなりズームしないと動きが見えない。

## 途中で止めたいとき

- スティック（送信機）を動かす、またはモードを変える → プログラムは即座に手を引く
- これは実機でも同じ動きにする約束（人間がいつでも取り返せる）

## いじって遊べる数字（buzz_motion.lua の頭にある）

| 名前 | 今の値 | 意味 |
|---|---|---|
| ROOM_X / ROOM_Y | 4.0 / 3.0 | 部屋の大きさ(m)。**実測待ち** |
| BURST_ALT | 2.0 | 急上昇の高さ(m)。**天井の実測待ち** |
| SWOOP_ALT | 0.8 | 着地前に滑り込む高さ(m) |
| BANK_ANGLE | 20 | 旋回の傾き(度)。骨格版ではまだ使っていない |

数字を変えたら保存して、シミュレータを起動し直すと反映される。

## 自動チェック（環境が壊れていないか確認したいとき）

上のデモと同じ操作を機械が全部やる:

```bash
python3 sitl/demo_flight.py    # リポジトリルートから。成功すると DEMO FLIGHT PASSED
```

## 仕組みメモ（1行ずつ）

- プログラムは `~/ardupilot/ArduCopter/scripts/` にリンクを置いてある（`ln -sf <このリポジトリ>/motion/buzz_motion.lua ~/ardupilot/ArduCopter/scripts/`）
- `SCR_USER1` は「スクリプト用の空きパラメータ」。地上局から数字を送るボタン代わりに使っている
- 本実装でやること: バンクターン・スピード調整・部屋寸法の実測値反映・実機用の安全チェック追加
