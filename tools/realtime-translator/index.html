Chrome で開くのが一番確実です

音声認識とオンデバイス翻訳はどちらも Chrome の機能です。Muse アプリの中ではマイク許可のダイアログが出ないことがあるため、共有リンクをコピーして Chrome に貼るか、Chrome のメニューからこのページを開き直してください。Chrome で開けば「聞き取り開始」を押したときに許可ダイアログが出ます。

  1. このページの共有リンクをコピーする
  2. Chrome を開いてアドレスバーに貼り付ける
  3. 「聞き取り開始」を押してマイクを許可する

🎧 Zoomで使うときのコツ

  • 相手の声を訳したい：イヤホンを外し、スピーカー再生にしてください。マイクがスピーカーの音を拾います。
  • イヤホン必須のとき：相手の声は拾えません。Zoomの字幕／チャットをコピーして「テキストを貼って翻訳」を使ってください。
  • 周りが静かなほど精度が上がります。話者が変わったら少し間を空けると区切りやすくなります。
  • 認識が自動で止まった場合は自動で再開します。それでも止まる場合はもう一度「聞き取り開始」を押してください。

🔒 仕組みと注意

  • 翻訳は Chrome のオンデバイス Translator API のみを使います。訳す文を外部のサーバーへ送る処理はこのページにはありません。使える間は文が端末の外に出ません。
  • オンデバイス翻訳が使えない環境では訳は出ません。その場合は聞き取った原文（文字起こし）を表示し、「この環境では翻訳機能が使えません。Chrome 最新版で開いてください」と案内します。
  • 音声認識はブラウザの Web Speech API を使います。ブラウザの仕様上、音声が認識サービスに送られる場合があります。
  • 翻訳は逐次処理のため、固有名詞や数字は聞き間違いが起きやすいです。大事な数字は原文も合わせて確認してください。
  • マイク許可をブロックした場合は、Chrome のアドレスバーのアイコンから許可し直してください。
対応ブラウザ：Mac の Google Chrome / Microsoft Edge（Web Speech API + Translator API）
