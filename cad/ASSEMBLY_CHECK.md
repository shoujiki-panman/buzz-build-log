# 機体全体の幾何チェック（2026-07-13）

「そもそも組み上がるのか」を、実測値と確定部品の3Dモデルで検証した結果。
モデル= [assembly_check.scad](assembly_check.scad) ／ 画像= [真上](preview/assembly_top.png)・[斜め](preview/assembly_iso.png)

## 判定: 幾何学的には成立する。ただし条件が2つ数字で出た

### 確認できたこと（実測・確定値ベース）

| 項目 | 数字 | 判定 |
|---|---|---|
| 隣接プロペラ同士の隙間 | **72mm** | ✅ 干渉なし（余裕大） |
| プロペラ円とトッププレート | 重ならない | ✅ 干渉なし |
| プロペラ回転面の高さ | バズ背面から約+60mm上 | ✅ 胴体とは立体的に分離 |

### 出てきた条件（ここが本当の発見）

1. **ポーズ制約が数字になった**: プロペラ円の内側の縁は機体中心から**36mm**。
   バズの体はこれより幅広（肩・腕）なので、真上から見るとプロペラ円の下に体がかかる。
   垂直方向の逃げ（約60mm）で成立しているため、**幅36mmより外側にある部位（腕・翼の飾り）を
   背面から上に55mm以上立ち上げてはいけない**。→ 腕は体側に沿わせるポーズ一択。Tポーズ不可
2. **重心の吸収幅が数字になった**: 電池（75g）はプレート上で前後±35mmしか動かせないため、
   吸収できるのは**バズ単体の重心ズレ±10mmまで**（264g × ズレ ÷ 電池75g ≒ 3.5倍のテコが必要）。
   ズレがそれ以上なら、マウント位置そのものをずらして補正する設計になる。
   → **Issue #1（単体重心の実測）が機体設計の最重要インプット**だと判明

### まだ仮定の数字（実測で差し替え — Issue #1, #2に対応）

| 仮定 | 置いた値 | 実測方法 |
|---|---|---|
| 体の最大幅（腕を体側ポーズ） | 90mm | 定規 |
| 胸の厚み | 55mm | 定規 |
| 上蓋からバズ背面までの高さ | 40mm | 定規 |
| 単体の重心位置 | 中心と仮定 | 吊り下げ（Issue #1） |

## 使い方

数字を直したら再生成:
```
openscad -o preview/assembly_top.png --imgsize=1000,1000 --projection=o --camera=0,0,-40,0,0,0,500 assembly_check.scad
openscad -o preview/assembly_iso.png --imgsize=1100,800 --camera=0,0,-30,60,0,35,520 assembly_check.scad
```

## 正直な注記

- このチェックが証明するのは**幾何（寸法の整合）と重心の計算**まで。はんだの成否・振動・
  実飛行の安定は物理でしか分からない（そのための段階ゲート）
- バズは箱で近似している。実物の形での最終確認は、実測値の反映＋（任意で）3Dスキャン合成で行う
