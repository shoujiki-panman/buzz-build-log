# cad/ — 機体部品の設計データ

## top_plate.scad — カーボントッププレート（90×60×3mm）

引き継ぎ§6-1のトッププレート。OpenSCADのパラメトリック設計で、
**ファイル冒頭の数字を書き換えて保存すれば形が変わる**。

入っている穴:
- 中央: FCスタック用 20×20mm・M3（Φ3.5、シリコングロメット考慮）
- 四隅: アーム結合用 M3×2穴ずつ（45°対角線上。角パイプ/平棒どちらにも対応する土台）
- 純正上蓋への固定穴: **TODO(採寸待ち)** — 上蓋のボス・ネジ穴位置を実測したら
  `lid_holes = [[x, y], ...]` に書き足す

## 見方（3D画面で回して見る）

1. OpenSCADは導入済み（`/Applications/OpenSCAD-2021.01.app`、Homebrew経由）
2. `top_plate.scad` を開いて F5（プレビュー）
3. 発注用のSTLは F6（レンダリング）→ File > Export > STL

✅ 2026-07-12 目視確認済み。確認画像= `preview/top_plate_top.png`（真上）/ `preview/top_plate_iso.png`（斜め）。
画像の再生成: `openscad -o preview/top_plate_top.png --imgsize=900,1100 --projection=o --camera=0,0,0,0,0,0,260 top_plate.scad`
